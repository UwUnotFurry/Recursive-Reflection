# Recursive Reflection

A small java library to do reflective stuff
recursively.

Initially part of an (admittedly insane)
other project I'm working on but has since
been extracted and genericised.<br>
Why? Idk, might be useful in other projects
I guess?

Currently, it only really does one thing:
searches field structure recursively.
Though more functionality may be added in
the future, or not? Who knows? Certainly not
me!<br>
To be honest I'm not entirely sure what else
could or should be added but what's
currently there is enough to suit my
purposes.
